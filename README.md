## 🚀 시작하기

### 1. YouTube Data API v3 키 발급

1. [Google Cloud Console](https://console.cloud.google.com/) 접속
2. 프로젝트 선택 (또는 새로 만들기)
3. **API 및 서비스** → **라이브러리** → "YouTube Data API v3" 검색 → **사용 설정**
4. **API 및 서비스** → **사용자 인증 정보** → **+ 사용자 인증 정보 만들기** → **API 키**
5. 키 복사 → **제한사항 설정** (YouTube Data API v3만 허용 권장)

### 2. 분석 도구 실행

1. `index.html` 다운로드
2. 브라우저에서 열기 (더블클릭)
3. API 키 입력
4. 끝!

---

## 📊 분석 도구 기능

### 탭 6개
- **영상 찾기** — 키워드 검색, 기여도/성과도 배지, 필터, 정렬
- **채널 분석** — 채널 입력 → 최근 영상 통계
- **채널 찾기** — 키워드로 채널 검색
- **키워드 분석** — 자동완성 기반 키워드 추천
- **수집함** — 관심 영상 저장, 폴더 분류, CSV 내보내기
- **채널 추적** — 관심 채널 등록, 새 영상 체크, 채널 비교

### 핵심 지표

| 지표 | 공식 | 의미 |
|------|------|------|
| **기여도** | 조회수 ÷ 구독자수 × 100 | 채널 밖으로 퍼졌나 |
| **성과도** | 조회수 ÷ 채널 평균 조회수 × 100 | 채널 안에서 특출났나 |
| **노출확률** | 최근 평균 조회수 ÷ 구독자수 × 100 | 채널이 건강한가 |

> ⚠️ 이 지표들은 유튜브 공식이 아니라 뷰트랩(유료 분석 도구)에서 사용하는 파생 지표입니다.

### 🤖 AI 분석 기능

## ✨ Google Opal로 영상 자동 생성

### 접속
- [opal.google](https://opal.google) 또는 Gemini → Gems

### 프롬프트
```
상품 프로모션 영상을 자동으로 만드는 앱을 만들어줘.

1단계: 상품명 입력
2단계: 상품 특징/장점 입력 (3가지)
3단계: VEO3로 15초 프로모션 영상 생성
4단계: 유튜브용 제목 생성 (SEO 최적화)
5단계: 유튜브용 설명 생성 (해시태그 포함)
6단계: 최종 프로모션 패키지 출력 (영상 + 제목 + 설명)
```
